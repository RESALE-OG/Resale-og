# RESALE OG — Buyer Only

Fresh buyer-only storefront for RESALE OG.

## Included
- Futuristic responsive storefront
- Product search and category filters
- Cart stored locally for the demo
- Sign-in/create-account UI placeholder
- No Sell Product / seller listing UI
- Express backend with product API
- Supabase config placeholder in `public/config.js`

## Run locally
1. `npm install`
2. `npm start`
3. Open `http://localhost:3000`

## Next production steps
Connect Supabase Auth, products database, storage, real cart/order tables, admin-only product management, and a payment provider. Do not put a Supabase service-role/secret key in frontend code.
